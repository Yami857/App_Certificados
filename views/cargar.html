Carga de Archivos de Calificaciones

Suba las plantillas oficiales en Excel para actualizar la base de datos y calcular certificaciones.

Archivo maestro con datos biográficos y programas matriculados (Hoja: Estudiantes).

Registro detallado de calificaciones por módulo y porcentajes de asistencia (Hoja: Evaluaciones).

Estructura requerida para el procesamiento:

  • Registro de Evaluaciones: Columnas obligatorias: Identificacion, Programa, Modulo, Nota, Asistencia_Pct, Fecha_Cierre.
  • Los números de identificación se procesan estrictamente como texto para preservar ceros a la izquierda.
